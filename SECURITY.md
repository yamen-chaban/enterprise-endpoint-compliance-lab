# Sicherheit und Datenschutz

- Nur fiktive Daten im öffentlichen Repository nutzen.
- Keine realen Hostnamen, Inventare, E-Mail-Adressen, Lizenzinformationen, Tenant-IDs oder Tickets hochladen.
- Niemals Kennwörter, API-Schlüssel, Zertifikate oder MFA-/OTP-Secrets committen.
- Keine Kursfolien oder geschützten Schulungsunterlagen von alfatraining kopieren.
- GitHub Secret Scanning und Push Protection aktivieren.
- Erst nach ausdrücklicher Zustimmung Skripte auf fremden oder verliehenen Geräten ausführen.
